# ForgePort

ForgePort ist eine modulare Sicherheits-Toolbox und ein Gateway für getrennte
oder streng kontrollierte Infrastrukturzonen. Das Projekt bündelt kontrollierten
Artefaktzugriff, kontrollierten HTTP/HTTPS-Egress, Identitätsintegration,
Richtlinien, Audit und eine gemeinsame Benutzeroberfläche.

ForgePort wird ausdrücklich nicht als Firewall vermarktet. Erweiterungen wie
Reverse Proxy, WAF, Firewall-Integration oder Security-Scanning sind mögliche
spätere Entwicklungen und keine Zusagen für Version 1.

## Repositories und Veröffentlichung

Die Komponenten werden als unabhängige Repositories entwickelt und versioniert.
Öffentliche Repositories werden erst nach Prüfung ihrer vollständigen Historie,
Geheimnisse, Drittanbieterbestandteile und Lizenzen freigegeben. Interne
Architektur- und Lizenzierungswerkzeuge bleiben privat.
